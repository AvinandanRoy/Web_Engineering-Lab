# W3Schools Clone

A simple responsive landing page inspired by [W3Schools](https://www.w3schools.com/), created by **Avinandan Roy (ID: 221-15-4899)** as part of a web development project.

## 📁 Project Structure
├── index.html    
├── style.css     


## 🚀 Features

- Responsive and modern design
- Sections for:
  - Tutorials
  - References
  - Exercises
  - Videos
- Highlighted tutorials for:
  - HTML
  - CSS
  - JavaScript
  - Python
  - SQL
  - React
- Certification promotion section
- Info section on learning benefits
- Clean navigation bar and footer

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, custom styling)
